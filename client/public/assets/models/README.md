# Model drop folder

Put downloaded CC0 model packs here (one sub-folder per pack) and map them in
`manifest.json`. Anything not mapped, or that fails to load, falls back to the
built-in procedural low-poly placeholder, so the game always runs.

See `manifest.example.json` for the format and `docs/ASSETS.md` (repo root)
for recommended packs, licences and how to map animation clips.
